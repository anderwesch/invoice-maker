# Labels sugeridas para o GitHub

Estas labels foram pensadas para manter o backlog simples e facil de priorizar.

## Prioridade

- `P0`: precisa entrar no proximo ciclo
- `P1`: alto valor, mas nao urgente
- `P2`: melhoria importante, pode esperar
- `P3`: estrutural ou de longo prazo

## Tipo

- `feature`: nova funcionalidade
- `bug`: defeito ou regressao
- `improvement`: melhoria incremental
- `tech-debt`: ajuste tecnico ou refatoracao
- `design`: refinamento visual ou de UX

## Area

- `clients`: cadastro e gestao de clientes
- `invoices`: criacao, edicao e fluxo de invoices
- `print`: layout de impressao e PDF
- `dashboard`: indicadores e visao geral
- `profiles`: perfis emissores
- `infra`: CI, setup, deploy, automacao
- `data`: persistencia, migracoes e modelo

## Fluxo

- `blocked`: depende de outra tarefa
- `good first issue`: bom ponto de entrada
- `needs-spec`: precisa de refinamento antes de implementar

## Sugestao pratica

Cada issue deve ter pelo menos:
- 1 label de prioridade
- 1 label de tipo
- 1 label de area

Exemplo:
- `P0`
- `feature`
- `invoices`
